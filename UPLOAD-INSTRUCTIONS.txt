GITHUB UPLOAD
1. Extract this ZIP on your computer.
2. Open amjadazizshah/my-portfolio on GitHub and choose the master branch.
3. Select Add file > Upload files. Upload the extracted files and folders at the repository root, preserving paths. Do not upload the ZIP itself. Keep any newer unrelated files in your repository.
4. Commit the update. Your existing Render auto-deploy can then build it.

If you only want to upload the files changed for the two reels, use:
  creative-portfolio/index.html
